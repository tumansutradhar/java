# Java Practice Programs

Collection of Java practice programs covering core Java concepts from basics to advanced topics including variables, data types, OOP principles, inheritance, packages, and access modifiers.

## About The Project

This repository serves as a hands-on learning resource for Java programming:
- What it covers: Java fundamentals (variables, data types, operators), object-oriented programming, inheritance, polymorphism, packages, and access modifiers
- What makes it useful: Sequential demo programs (Demo1-Demo21) showing progressive learning with commented examples
- What was learned: Core Java syntax, OOP concepts, calculator inheritance hierarchy, package organization, and access control mechanisms

The project includes 21 demo files demonstrating various Java concepts, calculator implementations showing inheritance, and examples of packages and access modifiers.

## Built With

- Java 8+
- Standard Java Libraries

## Getting Started

### Prerequisites

- Java Development Kit (JDK 8 or higher)
- Any Java IDE (IntelliJ IDEA, Eclipse, NetBeans) or text editor

### Installation

1. Clone the repo
   ```bash
   git clone https://github.com/tumansutradhar/java.git
   cd java
   ```

2. Compile a Java file
   ```bash
   javac Demo1.java
   ```

3. Run the program
   ```bash
   java Demo1
   ```

## Usage

**Demo Programs (Demo1.java - Demo21.java):**
Each demo file contains commented examples covering specific topics:
- Uncomment the code sections you want to run
- Compile and execute to see the output
- Examples cover: variables, data types, operators, loops, arrays, classes, objects, methods

**Calculator Programs:**
Demonstrates inheritance and polymorphism:
```bash
javac Calculator.java BasicCalculator.java AdvancedCalculator.java
java BasicCalculator
```
- `Calculator.java` - Base class with add/subtract operations
- `BasicCalculator.java` - Extends Calculator, adds multiplication/division
- `AdvancedCalculator.java` - Extended calculator functionality

**Packages:**
Examples of package organization:
```bash
cd Packages
javac Calculator.java
```

**Access Modifiers:**
```bash
cd AccessModifiers
javac Modifiers1.java
```
